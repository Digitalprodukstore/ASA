Dashboard Aman

Login untuk mengakses pengaturan BoothPro.

Buat akun owner lokal untuk mengunci Dashboard. Password disimpan sebagai hash PBKDF2, bukan plaintext.

Gunakan salah satu recovery code yang dibuat saat pengamanan akun diaktifkan. Recovery code hanya dapat dipakai sekali.

Aktifkan verifikasi 2 langkah dengan aplikasi Authenticator. Simpan secret dan recovery codes di tempat aman.

Catatan keamanan: karena BoothPro ini berjalan sebagai HTML di browser, login lokal tidak menggantikan autentikasi server. Untuk akun komersial multi-device dan reset lewat email, gunakan backend/auth provider. Jangan simpan Server Key Midtrans di HTML produksi.

Printer & Ukuran Cetak

Cocok untuk printer WiFi/thermal sublimasi 4x6 (DNP, HiTi, CP1500). Pilih ukuran kertas:

Gunakan dialog print bawaan OS → pilih printer WiFi. Untuk cetak langsung tanpa dialog (kiosk mode), aktifkan "Print silently" di browser.

Kamera

Webcam USB, kamera HP/tablet (iOS/Android), dan DSLR yang dikenali browser sebagai webcam. DSLR via SDK memerlukan bridge.

Hardware Bridge

Koneksi nyata ke printer/kamera eksternal melalui aplikasi bridge lokal. Browser tetap memakai kamera WebRTC jika bridge kosong.

Catatan: HTML browser tidak dapat menjamin silent-print/akses driver printer DSLR secara universal. Bridge adalah jalur yang benar untuk perangkat fisik.
