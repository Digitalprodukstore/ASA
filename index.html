Durasi sesi

QRIS

Upload gambar QRIS merchant. Disimpan lokal di kiosk.

Voucher

Satu kode per baris. Format: KODE|diskon_nominal. Contoh DEMO|10000

Paket Harga

Link Soft File

Isi jika kamu sudah punya backend/cloud yang menerima session ID. Tanpa backend, QR hanya berisi ID dan info sesi agar tidak membuat QR palsu.

Frame Galeri

Upload frame buatanmu di Dashboard. Galeri ini dipakai bersama oleh pemilihan awal, review, dan editor.

Tampilan Kiosk

Atur warna latar, gaya, gambar latar, dan warna aksen.

Cloudinary Soft File

Opsional. Isi Cloud Name + unsigned Upload Preset. API Secret jangan pernah dimasukkan ke HTML.

Share / QR Endpoint

Untuk QR sungguhan yang membuka foto + GIF dari HP customer, gunakan URL halaman share/backend.

Watermark & Tanggal Frame

Tulisan ini dibuat oleh BoothPro di area footer hasil foto. Jika watermark sudah menyatu di file PNG frame, tulisan tersebut tidak bisa dihapus dari HTML.

Branding & Home Screen

Sesuaikan nama booth, logo, tagline, judul halaman awal, dan deskripsi. Logo hanya disimpan di browser kiosk.

Cetak Tambahan

Harga per tambahan strip. Customer wajib membayar QRIS sebelum cetak tambahan diizinkan.

Kamera

Webcam USB dan DSLR yang dikenali browser sebagai webcam dapat digunakan. DSLR dengan SDK khusus memerlukan bridge aplikasi.
